This is intended for development testing only. This assumes that your website is currently running, and all environment variables are properly configured.

To login the application with magic link, make sure that convex development server is currently running with `pnpm dlx convex dev` before signing in with magic link on the website interface. After signing in, check the terminal logs to retrieve the link for logging in to the platform.
